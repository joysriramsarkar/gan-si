# গান-সি | সুর সাধনা Pro (Gan-si Sur Sadhana)

> আধুনিক ভারতীয় ও বাংলা সঙ্গীত রেওয়াজ, লাইভ ভোকাল পিচ ট্রেইনার ও স্টুডিও স্যুট (Node.js & Express Full-Stack Application)

---

## 🎯 মূল বৈশিষ্ট্যসমূহ (Core Features)

1. **ভোকাল পিচ ডিটেক্টর (Live Vocal Pitch Tuner)**:
   - প্যারাবলিক ইন্টারপোলেশনযুক্ত অটোকোরিলেশন অ্যালগরিদম ও ইএমএ স্মুথিং।
   - রিয়েল-টাইম সেন্ট গেজ (-50c থেকে +50c) ও নিখুঁত সুরে নিয়ন গ্রিন ভিজ্যুয়াল ফিডব্যাক।
   - সপ্তক সনাক্তকরণ (মন্দ্র, মধ্য, তার সপ্তক) এবং সুরের নির্ভুলতা ট্র্যাকিং (% In Tune)।

2. **অ্যাকোস্টিক তানপুরা ড্রোন (Tanpura Suite with Javari)**:
   - ভারতীয় তানপুরার সিল্ক-থ্রেড জোয়ারি (Javari buzz & metallic shimmer) সমৃদ্ধ ওয়েব অডিও সিন্থেসিস।
   - ৪টি তারের ছন্দময় প্ল্যাকিং অ্যানিমেশন ও বিভিন্ন রাগের ১ম তার টিউনিং (Pa, Ma, Ni, Dha)।

3. **ভার্চুয়াল হারমোনিয়াম (Interactive Harmonium)**:
   - ডাবল-রিড অ্যাকোস্টিক ফিল্টারযুক্ত ২ অক্টেভের হারমোনিয়াম।
   - মাউস ও টাচ কন্ট্রোলের পাশাপাশি কিবোর্ড হটকিজ (`A`, `W`, `S`, `E`, `D`...) সাপোর্ট।

4. **তবলা ও ছন্দ মেট্রোনম (Tabla Taal Machine)**:
   - বায়াঁর বেস স্লাইড ও ডায়াঁ-র মেটালিক শব্দের বাস্তবসম্মত সিন্থেসিস।
   - ত্রিতাল (১৬ মাত্রা), কাহারবা (৮ মাত্রা), দাদরা (৬ মাত্রা), রূপক (৭ মাত্রা)।

5. **অলংকার ও পল্টা প্র্যাকটিস (Alankars Library)**:
   - শাস্ত্রীয় বিভিন্ন অলংকার ও পল্টা অনুশীলনের ইন্টার‍্যাক্টিভ গাইড।

6. **ভারতীয় শাস্ত্রীয় রাগ অভিধান (Ragas Explorer)**:
   - ইমন, বিলাবল, ভৈরব, ভৈরবী, কাফি, ভূপালী, আশাবরী, খাম্বাজ ইত্যাদি রাগের বিবরণ।

7. **সার্ভার-সাইড অডিও রেকর্ডিং (Audio Recording & Streaming)**:
   - মাইক্রোফোন এবং তানপুরার সুর একসাথে রেকর্ড করে সরাসরি Node.js সার্ভারে স্থায়ীভাবে সংরক্ষণ ও ডাউনলোড করার সুবিধা।

## 🚀 ইনস্টলেশন ও রান করার নিয়ম (Getting Started)

### ১. ডিপেন্ডেন্সি ইনস্টল করুন
```bash
npm install
```

### ২. প্রোডাকশন সার্ভার চালু করুন
```bash
npm start
```
অথবা ডেভেলপমেন্ট মোডে (Auto-reload সহ):
```bash
npm run dev
```

### ৩. ব্রাউজারে প্রবেশ করুন
যেকোনো ব্রাউজারে গিয়ে ওপেন করুন:
[http://localhost:3000](http://localhost:3000)

## 📡 REST API ডকুমেন্টেশন (Backend Endpoints)

| মেথড | এন্ডপয়েন্ট | বিবরণ |
|---|---|---|
| `GET` | `/api/health` | সার্ভার হেলথ ও স্ট্যাটাস চেক |
| `GET` | `/api/ragas` | সমস্ত রাগের তালিকা (ফিল্টারিং: `?thaat=...`, `?search=...`) |
| `GET` | `/api/ragas/:id` | নির্দিষ্ট রাগের তথ্য |
| `GET` | `/api/alankars` | অলংকার ও পল্টার তালিকা |
| `GET` | `/api/recordings` | সার্ভারে সংরক্ষিত সমস্ত রেকর্ডিংয়ের তালিকা |
| `POST` | `/api/recordings` | অডিও ফাইল আপলোড ও সংরক্ষণ (Multipart form-data) |
| `DELETE` | `/api/recordings/:filename` | সংরক্ষিত অডিও ফাইল মুছে ফেলা |
| `GET` | `/recordings-stream/:filename` | অডিও স্ট্রিমিং ও প্লেব্যাক |

## 📁 প্রোজেক্ট ডিরেক্টরি স্ট্রাকচার (Folder Structure)

```
Gan-si/
├── package.json          # Node.js প্রজেক্ট কনফিগারেশন ও স্ক্রিপ্ট
├── server.js             # Express.js সার্ভার ও REST API রাউট
├── .env                  # এনভায়রনমেন্ট কনফিগারেশন (PORT, UPLOAD_DIR)
├── data/                 # JSON ডাটাবেস
│   ├── ragas.json        # রাগসমূহের তথ্য
│   └── alankars.json     # অলংকারসমূহের তথ্য
├── uploads/              # সার্ভার-সাইড অডিও রেকর্ডিং স্টোরেজ
├── public/               # ক্লায়েন্ট-সাইড স্ট্যাটিক ফ্রন্টএন্ড এসেট
│   ├── index.html        # মূল সিঙ্গেল পেজ অ্যাপ্লিকেশন মার্কআপ
│   ├── style.css         # আধুনিক ডার্ক স্টুডিও গ্লাস-মর্ফিক স্টাইল
│   ├── audio-engine.js   # তানপুরা, হারমোনিয়াম, তবলা সিন্থেসিস ইঞ্জিন
│   ├── pitch-detector.js # প্যারাবলিক অটোকোরিলেশন পিচ ইঞ্জিন
│   └── app.js            # ইউআই স্টেট ও ব্যাকএন্ড API ইন্টিগ্রেশন
└── README.md             # পূর্ণাঙ্গ গাইডলাইন
```
